Learn

A ply is stiff along its fibers and soft across them. When the fibers turn by an angle \(\theta\), the ply stiffness in the x-y axes changes:

\[ [\bar{Q}] = [T_\varepsilon]^{\mathsf{T}}\,[Q]\,[T_\varepsilon] \]

At 0° and 90°, a pull along x only stretches the ply. At any other angle, the pull also shears it, because \(\bar{Q}_{16} \neq 0\). A single ply is balanced only at 0° or 90°.

Python

Each lesson gives a Python script that computes the same numbers.

import numpy as np

def strain_transform(theta_deg: float) -> np.ndarray:
    """Return the matrix that turns global strains into fiber-axis strains."""
    c = np.cos(np.radians(theta_deg))
    s = np.sin(np.radians(theta_deg))
    return np.array([[c * c, s * s, c * s],
                     [s * s, c * c, -c * s],
                     [-2.0 * c * s, 2.0 * c * s, c * c - s * s]])
